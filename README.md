## 🎯 About

A bilingual (Arabic/English) portfolio website built to showcase Marwan's professional experience, skills, and work — with a focus on opportunities in the **Gulf region** (Saudi Arabia, UAE, Qatar, Kuwait).

### Features

- ✅ **Bilingual** — Arabic (RTL) + English (LTR)
- ✅ **Dark/Light mode** with saved preference
- ✅ **Auto Gallery** — images loaded dynamically from the `gallery/` folder via GitHub API
- ✅ **Fully responsive** — works perfectly on mobile & desktop
- ✅ **PWA-ready** — installable on mobile devices
- ✅ **Offline support** via Service Worker
- ✅ **SEO optimized** with structured data (JSON-LD)
- ✅ **Smooth animations** on scroll
